## 항목별 근거

### #1 "새 프로젝트" 버튼 발견성
`toolbar-ghost-button`(투명 배경, 12.5px)과 `toolbar-export-button`(pill, accent 배경 + 그림자)이 같은 헤더에 공존.
`Toolbar.tsx:173-190`, `App.css:136-152`, `App.css:168-190`.
※ 다만 "새 프로젝트"는 브랜드 zone에, "내보내기"는 `toolbar-zone-spacer`로 분리된 반대쪽 끝에 있어 물리적으로 인접하지는 않음 — 지적의 핵심(스타일 약함)은 유효.

### #2 Undo/Redo 발견성
아이콘(↶/↷)만 노출, `aria-label="되돌리기"` / `aria-label="다시 실행"`은 존재해 스크린리더 접근성은 확보됨
(`Toolbar.tsx:270-289`). 문제는 **접근성**이 아니라 **시각적 발견성**(sighted user가 아이콘 의미를 못 알아챔)에 가까움 —
"일관성/발견성" 카테고리로 재분류 권장.

### #3 툴바 과밀
브랜드/워크스페이스/파일 3개 zone에 select 2개 + ghost 버튼 3개 + undo/redo/도움말/내보내기까지 한 헤더에 배치,
`.toolbar { flex-wrap: wrap }` (`App.css:68`)로만 대응.

### #4 도구 레일 라벨/버튼 크기
`tool-rail-label { font-size: 10px }` (`App.css:669`)는 확인되어 라벨이 작다는 지적은 타당.
단 버튼 높이는 `padding 8px+7px + glyph 20px + gap 4px + label ~12px ≈ 51px`로 계산되어 44px 터치 타겟 기준을
오히려 상회함 (`App.css:627-671`). 실측(브라우저 렌더링) 검증 필요 — 코드 기준으로는 "높이 부족" 주장은 반증됨.

### #5 도구 패널 헤더 중복
`App.tsx:650-651`의 `tool-panel-column-head`가 `<h3>{TOOL_TITLES[activeTool]}</h3>`로 "전사"/"번역" 등을 표시하는데
왼쪽 `ToolRail`의 `tool-rail-label`도 같은 텍스트 사용.

### #6 260px 고정폭 컨트롤 줄바꿈
`.tool-panel-column { width: 260px }` (`App.css:674`)인데 `SubtitleStylePanel.tsx`의 `panel-row`는
select+number+checkbox+button을 한 줄에 배치하고 `.panel-row { flex-wrap: wrap }` (`App.css:1650`)로만 처리.

### #7 색상 선택기 기본값
`SubtitleStylePanel.tsx:138-170`에 `<input type="color">`가 그대로 3곳(글자색/외곽선색/배경색) 사용,
`App.css:1701-1709`는 테두리/크기만 커스텀.

### #8 타임라인 핸들/마커 크기
`.timeline-marker-handle { width: 6px }` (`App.css:932`), `.timeline-marker { min-width: 3px }` (`App.css:885`).

### #9 카라오케 색상 하드코딩
`.subtitle-karaoke-highlight { color: #ffd54a; }` (`App.css:813`) — `--accent`/`--text` 등 디자인 토큰 미사용.

### #10 세그먼트 행 컨트롤 숨김
`segment-select-checkbox` (`App.css:1261`), `segment-row-actions` (`App.css:1234`), `reviewed-toggle` (`App.css:1217`)
모두 기본 `opacity: 0`, `:hover`/`.selected`/`.checked`에서만 노출.

### #11 필터 탭 색상 전용 구분
`SegmentList.tsx`의 필터 탭은 `active`/`warn`/`ok` 클래스 조합뿐이고 CSS(`App.css:1404-1418`)도 배경색만 변경 —
아이콘·패턴 등 추가 신호 없음.

### #12 상세 검수 패널 액션 버튼 무게
`SegmentDetailPanel.tsx:196-226`의 `.timing-actions` 4개 버튼 중 삭제 버튼만 `danger-button` 클래스가 있지만
CSS(`App.css:1607-1611`)는 `color`/`border-color`만 빨간색으로 바꿀 뿐 padding·크기·배경은 동일. `margin-left: auto`로
오른쪽에 붙지만 시각적 무게는 나머지 버튼과 같음.

## 권장 우선순위 (수정 시 참고용, 이번 라운드는 미적용)

1. 도구 패널 헤더 ↔ 레일 라벨 중복 제거 (#5)
2. 도구 레일 라벨 폰트 확대 (#4의 라벨 부분만)

4. 세그먼트 행 컨트롤 상시 노출 또는 최소 투명도 부여 (#10)
5. 카라오케 색상 등 하드코딩 값의 디자인 토큰화 (#9)
