## 1. 수집하는 개인정보 항목

### 로컬 전용 사용 시 (현재)

서버로 전송되는 개인정보가 없습니다. 업로드한 영상/오디오와 전사·번역 결과는 사용자의
컴퓨터 안(`data/` 폴더)에만 저장됩니다. 자세한 내용은 앱 내 도움말의 "데이터 보호" 섹션을
참고하세요.

### 클라우드 서비스 전환 시 (예정, 더미 — 실제 설계 확정 후 교체)

- 회원가입 시: 이메일 주소, 비밀번호(해시 저장) 또는 소셜 로그인 식별자
- 결제 시: 카드 정보는 자체 저장하지 않고 PG사(결제대행사)에 위탁 처리
- 서비스 이용 시: 업로드 파일은 처리 완료 후 일정 기간(예: 30일) 뒤 자동 삭제
- 자동 수집 항목: 접속 로그(IP, 접속 일시), 쿠키, 기기/브라우저 정보

정산(결제 및 환불 처리), 고객 문의 대응 및 공지사항 전달을 위해 개인정보를 수집·이용합니다.
(더미 — 실제 목적 확정 후 교체)

엔진을 직접 활성화한 경우, 번역 대상 텍스트가 해당 외부 API 제공업체로 전송될 수 있습니다.

사업자 확정 후 교체)에 개인정보 처리 업무를 위탁할 수 있습니다.
