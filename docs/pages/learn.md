# 사용법 배우기

> 이 페이지는 앱 안의 **도움말(?) 버튼**과 같은 내용을 다룹니다. 실제 서비스 페이지로
> 만들 때는 앱 내 `HelpModal` 콘텐츠를 소스로 동기화하세요(내용이 두 곳에서 따로 관리되면
> 금방 어긋납니다).

## 기본 흐름

1. 상단 **+ 업로드**로 영상/오디오 파일을 올립니다.
2. **전사** 탭에서 Whisper 모델 크기를 골라 자막을 추출합니다.
3. **번역** 탭에서 방향(한→영/영→한)과 엔진을 골라 번역을 붙입니다.
4. 문장 목록에서 클릭 → 상세 패널에서 시작/종료 시간, 원문, 번역문을 수정합니다.
5. **스타일** 탭에서 자막 글꼴/색상/위치를 설정합니다.
6. **내보내기**로 자막 파일을 받거나 영상으로 번인 렌더링합니다. **AI 검수**로 교정을 받을
   수도 있습니다.

## 더 자세히

- Whisper 모델 크기별 속도/정확도 비교, 화자 분리, 가독성 검사, 용어집, 번역 메모리,
  분할/병합, 찾기·바꾸기, 타임라인 드래그 편집, 키보드 단축키, 문제 해결(트러블슈팅) —
  전부 앱 안 도움말(우측 상단 **?** 버튼)에 정리되어 있습니다.
- 데이터가 어디에 저장되는지는 도움말의 "데이터 보호" 섹션 참고.
